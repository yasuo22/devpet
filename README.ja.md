# 🐾 DevPet · 開発者デスクトップペット

![Version](https://img.shields.io/badge/version-v1.1.0-blue) ![License](https://img.shields.io/badge/license-MIT-green)

> **開発者の仕事/生活をともにするデスクトップ小型ペット** —— 天気・相場・GitHub作品展示・ポモドーロを統合し、仕事のデスクトップを退屈にしません。

![DevPet](devpet/assets/favicon.svg)

ゼロ依存・完全静的・すぐ使える**開発者デスクトップマスコット**アプリです。インラインSVGで描かれたかわいいマスコットが内蔵されており、ドラッグ・ロック・気分/天気反応に対応し、開発者向け情報パネル（天気・株式・暗号通貨・GitHub作品・ポモドーロ）を統合しています。

---

## ✨ 主要機能

| 機能 | 説明 |
| --- | --- |
| 🐱 **マスコットコア** | インラインSVG描画、idle / sleep / happy / sad / working / chase の6状態マシン |
| 🌦️ **天気反応** | 晴れならhappy、雨/雪ならsad、服/小物の反応を拡張可能 |
| 📈 **株式 / 暗号通貨相場** | 株式（Stooq CSV）+ 暗号通貨（CoinGecko）リアルタイム相場 |

| 🧩 **ウィジェット ドラッグ / オンオフ** | 各情報パネルをドラッグで並べ替え・閉じる可能 |
| 🪪 **ペットメタデータ** | ペット名 / タイプ(kind) / 気質(vibes) / 性別 / 職業 / 性格 / 配色 / sprites を設定可能、petdexエコシステムに準拠 |
| 🖌️ **ペットエディタUI** | 名前・タイプ・気質・性別・職業・性格・配色を視覚的に編集、リアルタイムプレビュー |
| 🔗 **GitHubアカウント連携** | 設定パネルでユーザー名を入力し、リアルタイムにコントリビューションヒートマップ連携 |
| 💾 **オフライン縮退** | 外部APIリクエスト失敗時は自動で内蔵データに切替、オフラインでも利用可 |
| 🎨 **ダーク/ライトテーマ** | ワンクリック切替、選択を永続化 |
| 🎨 **テーママーケット（マルチペット）** | 内蔵6種のペットテーマ（カラー茶トラ猫含む）、ワンクリック切替 + ペット設定のエクスポート/インポート |
| 🔔 **通知サービス（Webhook）** | Discord / Slack / Telegram を設定、ポモドーロ/いいね/協業イベントをプッシュ |
| 🤝 **協業モード** | オンライン状態 + プロジェクト共有進捗 + 協業招待リンク |
| 🧵 **バブル優先キュー** | 重要な通知を優先表示、低優先度は割り込まず待機 |
| 🦋 **カラー茶トラ猫** | ユーザー入力活動を検出 → 蝶を追う；15分アイドル → 猫ベッドで睡眠 |
| 🐟 **キャットフードシステム** | token消費 → キャットフード蓄積、4時間ごとに給餌リマインド、複数グレード |
| 🤖 **Codex token連携** | API / 手動で実際のtoken消費を報告、ウォレットを自動同期 |
| 🛒 **キャットフード購入** | ウォレットtokenで複数グレードのキャットフードを購入（基本/サーモン/マグロ/和牛） |
| 🏅 **ペット成長システム** | 給餌/交流/集中で親密度と経験値を上昇、レベルアップで高級フードを解放 |
| 🍅 **ポモドーロ連携** | 集中セッションでXP + 親密度を獲得、休憩時に給餌で回復、時間ロジックを自動接続 |
| ⚡ **コーディング活動反応** | Codex token増分を監視 → ペットがコーディングエージェントの活動にリアルタイム反応（working + 応援バブル） |

## 🚀 クイックスタート

### 方法1: ブラウザで直接実行（推奨）

```bash
# リポジトリをクローン
git clone <repo-url>
cd DevPet

# ブラウザで index.html を直接開く
open devpet/index.html        # macOS
start devpet/index.html       # Windows
xdg-open devpet/index.html    # Linux
```

> 完全静的・ゼロ依存 — `npm install`不要、ビルド不要、ダブルクリックですぐ使えます。

### 方法2: ローカルHTTPサーバー

```bash
cd devpet
python3 -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

## 🎮 マスコット状態マシン

```
idle ──► sleep   （アイドル30秒超え；茶トラ猫15分）
idle ──► happy   （天気が良い / いいね）
idle ──► sad     （天気が悪い / データ取得失敗）
idle ──► working （ポモドーロ実行中）
idle ──► chase   （茶トラ猫が入力を検出 → 蝶を追う）
chase ─► idle    （蝶のアニメ終了 / 入力停止）
sleep ─► chase   （茶トラ猫：入力を検出 → 起きて蝶を追う）
sleep ─► idle    （クリックで起床）
locked ─► 全状態でドラッグ無効
```

## 🛠️ カスタム設定

すべての設定は `devpet/js/config.js` に集約されており、簡単に変更できます:

- **APIエンドポイント**: 天気 / 相場 / GitHubデータソースを変更
- **マスコット位置**: デフォルトの初期位置
- **ウィジェットオンオフ**: `DEFAULT_WIDGETS` が表示するパネルを制御
- **ポモドーロ**: 作業時間 / 休憩時間 / 長休憩サイクル
- **オフラインデータ**: オフライン時の縮退データ

## 🔐 セキュリティとデプロイ

### デプロイ環境

- **Web**: `devpet/` は完全静的アプリ、ブラウザで直接開くか任意の静的サーバーでホスティング、ビルド不要。
- **デスクトップ**: `tauri/` はTauri 2デスクトップシェル; `npm install` + `tauri build` が必要（RustツールチェーンとシステムWebKitライブラリに依存）。
- **CI**: リポジトリに `.cnb.yml` パイプラインが内蔵され、`push` / `pull_request` 時にJS構文チェックとフロントエンドビルドを自動実行。
- **無視ファイル**: ルート `.gitignore` は `node_modules`、`target`、ビルド成果物、ローカル秘密鍵を無視。

### セキュリティモデル

DevPetはサーバーを持たない完全フロントエンドのローカルアプリで、「最小権限」の原則に従います:

- **外部データのエスケープ**: GitHub / 天気 / 相場などの外部APIが返すテキスト（bio、リポジトリ説明、コミットメッセージ、都市、相場名など）はレンダリング前にHTMLエスケープされ、XSSを防止します。
- **ローカルデータのエスケープ**: ペット設定、協業状態などのユーザー書き込みデータ（インポートしたペット設定含む）もDOMに描画前にエスケープされます。
- **Tauri CSP**: `tauri.conf.json` のCSPは `img-src` をGitHubアバター/ヒートマップドメインのみに制限し、インジェクションリスクを低減。
- **API Key**: Codex API Keyはローカルブラウザの `localStorage` のみに保存され、共有/公共PCでは設定しないでください。
- **Webhook**: 通知Webhook URLはユーザーが設定し、リクエストはローカルブラウザから発行、イベントプッシュのみに使用されます。

### 既知の制限

- 完全フロントエンドではサーバー側セッション認証を提供できないため、機密の認証情報（API Keyなど）はローカルで慎重に扱ってください。
