# 🐾 DevPet · 개발자 데스크톱 펫

![Version](https://img.shields.io/badge/version-v1.1.0-blue) ![License](https://img.shields.io/badge/license-MIT-green)

> **개발자의 작업/생활을 함께하는 데스크톱 소형 펫** — 날씨, 시세, GitHub 작품 전시, 뽀모도로가 통합되어 작업 데스크톱이 더 이상 지루하지 않게 해줍니다.

![DevPet](devpet/assets/favicon.svg)

제로 의존성, 순수 정적, 바로 사용 가능한 **개발자 데스크톱 마스코트** 애플리케이션입니다. 인라인 SVG로 그려진 귀여운 마스코트가 내장되어 있으며, 드래그, 잠금, 기분/날씨 반응을 지원하고 개발자에게 유용한 정보 패널(날씨, 주식, 암호화폐, GitHub 작품, 뽀모도로)이 통합되어 있습니다.

## ✨ 핵심 기능

| 기능 | 설명 |
| --- | --- |
| 🐱 **마스코트 코어** | 인라인 SVG 드로잉, idle / sleep / happy / sad / working / chase 6가지 상태 머신 지원 |
| 🌦️ **날씨 반응** | 맑은 날 happy, 비/눈 sad, 옷/소품 반응 확장 가능 |
| 📈 **주식 / 암호화폐 시세** | 주식(Stooq CSV) + 암호화폐(CoinGecko) 실시간 시세 |
| 🐙 **GitHub 작품** | 사용자 공개 저장소, Star 수, 기여 히트맵, 최근 커밋/PR 표시 |
| 🍅 **뽀모도로** | 25+5 뽀모도로 기법, 작업/휴식 상태 자동 전환 |
| 🧲 **드래그 / 잠금** | 위치 자유 드래그, 원클릭 잠금으로 오작동 방지 |
| 🧩 **위젯 드래그 / 켜기·끄기** | 각 정보 패널 드래그 정렬 및 닫기 가능 |
| 🪪 **펫 메타데이터** | 펫 이름 / 유형(kind) / 기질(vibes) / 성별 / 직업 / 성격 / 색상 / sprites 설정 가능, petdex 생태계 정렬 |
| 🖌️ **펫 편집기 UI** | 이름, 유형, 기질, 성별, 직업, 성격, 색상을 시각적으로 수정, 실시간 미리보기 |
| 🔗 **GitHub 계정 연동** | 설정 패널에서 사용자 이름 입력, 실시간 기여 히트맵 연동 |
| 💾 **오프라인 폴백** | 모든 외부 API 요청 실패 시 내장 데이터로 자동 전환, 오프라인에서도 사용 가능 |
| 🎨 **다크/라이트 테마** | 원클릭 다크/라이트 테마 전환, 선택 영구 저장 |
| 🎨 **테마 마켓 (멀티 펫)** | 기본 제공 6종 펫 테마(컬러 얼룩고양이 포함), 원클릭 전환 + 펫 설정 내보내기/가져오기 |
| 🔔 **알림 서비스 (Webhook)** | Discord / Slack / Telegram 설정, 뽀모도로/좋아요/협업 이벤트 푸시 |
| 🤝 **협업 모드** | 온라인 상태 + 프로젝트 공유 진행도 + 협업 초대 링크 |
| 🧵 **버블 우선순위 큐** | 중요 알림 우선 표시, 낮은 우선순위는 끼어들지 않고 대기 |
| 🦋 **컬러 얼룩고양이** | 사용자 입력 활동 감지 → 나비 쫓기; 15분 유휴 → 고양이 집에서 잠 |
| 🐟 **고양이 사료 시스템** | token 소모 → 사료 누적, 4시간마다 급여 알림, 여러 등급 |
| 🤖 **Codex token 연동** | API / 수동으로 실제 token 소모 보고, 지갑 자동 동기화 |
| 🛒 **고양이 사료 구매** | 지갑 token으로 여러 등급 사료 구매(기본/연어/참치/와규) |
| 🏅 **펫 성장 시스템** | 급여/상호작용/집중으로 친밀도와 경험치 상승, 레벨업으로 고급 사료 잠금 해제 |
| 🍅 **뽀모도로 연동** | 집중 세션에서 XP + 친밀도 획득, 휴식 시 급여로 회복, 시간 로직 자동 연결 |
| ⚡ **코딩 활동 반응** | Codex token 증분 감지 → 펫이 코딩 에이전트 활동에 실시간 반응(working + 응원 버블) |

## 🚀 빠른 시작

### 방법 1: 브라우저에서 직접 실행 (권장)

```bash
# 저장소 클론
git clone <repo-url>
cd DevPet

# 브라우저에서 index.html 직접 열기
open devpet/index.html        # macOS
start devpet/index.html       # Windows
xdg-open devpet/index.html    # Linux
```

> 순수 정적, 제로 의존성 — `npm install` 불필요, 빌드 단계 없음, 더블클릭만 하면 됩니다.

### 방법 2: 로컬 HTTP 서버

```bash
cd devpet
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 🔧 기술 스택

| 항목 | 선택 | 설명 |
| --- | --- | --- |
| 실행 방식 | 순수 정적 HTML/CSS/JS | 제로 의존성, 더블클릭만으로 실행 |
| 데스크톱 셸 | **Tauri 2** (Rust 백엔드) | 전역 항상 위 / 클릭 통과 / 트레이 / 알림 |
| 상태 관리 | `localStorage` | 펫 위치/기분/설정 영구 저장 |

## 🎮 마스코트 상태 머신

```
idle ──► sleep   （유휴 30초 초과; 얼룩고양이 15분）
idle ──► happy   （날씨 좋음 / 좋아요）
idle ──► sad     （날씨 나쁨 / 데이터 불러오기 실패）
idle ──► working （뽀모도로 실행 중）
idle ──► chase   （얼룩고양이가 입력 감지 → 나비 쫓기）
chase ─► idle    （나비 애니메이션 종료 / 입력 중단）
sleep ─► chase   （얼룩고양이: 입력 감지 → 깨어나 나비 쫓기）
sleep ─► idle    （클릭으로 깨우기）
locked ─► 모든 상태에서 드래그 비활성
```

## 🔐 보안 및 배포

### 배포 환경

- **웹**: `devpet/`은 순수 정적 애플리케이션, 브라우저에서 직접 열거나 임의 정적 서버에서 호스팅, 빌드 불필요.
- **데스크톱**: `tauri/`는 Tauri 2 데스크톱 셸; `npm install` + `tauri build` 필요 (Rust 툴체인과 시스템 WebKit 라이브러리 의존).
- **CI**: 저장소에 `.cnb.yml` 파이프라인이 내장되어 `push` / `pull_request` 시 JS 구문 검사와 프론트엔드 빌드를 자동 실행.
- **무시 파일**: 루트 `.gitignore`는 `node_modules`, `target`, 빌드 산출물, 로컬 비밀을 무시.

### 보안 모델

DevPet은 서버 없는 순수 프론트엔드 로컬 애플리케이션으로, 「최소 권한」 원칙을 따릅니다:

- **외부 데이터 이스케이프**: GitHub / 날씨 / 시세 등 외부 API가 반환한 텍스트(bio, 저장소 설명, 커밋 메시지, 도시, 시세 이름 등)는 렌더링 전 HTML 이스케이프되어 XSS를 방지합니다.
- **로컬 데이터 이스케이프**: 펫 설정, 협업 상태 등 사용자 작성 데이터(가져온 펫 설정 포함)도 DOM에 렌더링 전 이스케이프됩니다.
- **Tauri CSP**: `tauri.conf.json`의 CSP는 `img-src`를 GitHub 아바타/히트맵 도메인만으로 제한하여 주입 위험을 낮춥니다.
- **API Key**: Codex API Key는 로컬 브라우저 `localStorage`에만 저장되며, 공유/공용 PC에서는 설정하지 마십시오.
- **Webhook**: 알림 Webhook URL은 사용자가 직접 설정하며, 요청은 로컬 브라우저에서 발생, 이벤트 푸시에만 사용됩니다.

### 알려진 제한

- 순수 프론트엔드는 서버 측 세션 인증을 제공할 수 없으므로, 민감한 자격 증명(예: API Key)은 로컬에서 신중하게 사용하십시오.
